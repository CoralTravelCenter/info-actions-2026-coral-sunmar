# info-actions-2026

Лендинг «Акции» (Coral / Sunmar). Мигрирован из `vue-b2c-projects_2025/info_actions_2025`
на сборщик `b2c-landing-vite` (schemaVersion 2, стек vue + html + scss).

```bash
npm run check
npm run dev
npm run build
```

## Блоки (`src/order.json`)

| Блок | Разметка | Стили | Скрипт |
|---|---|---|---|
| `text` | `markup/text.html` | `styles/text.scss` (подключает общие стили) | — |
| `info-actions` | `markup/info-actions.html` | `styles/info-actions.scss` | `scripts/info-actions.js` |
| `contacts` | `markup/contacts.html` | `styles/contacts.scss` | — |

## Источник данных об акциях

| Режим | Откуда данные |
|---|---|
| `npm run build` (прод) | внешний скрипт сайта кладёт массив в `window._promotion_settings` |
| `npm run dev` | локальная фикстура `data/promotions.dev.js` |

`loadPromotions()` читает глобал **синхронно, без ожидания**, и только если его нет,
в dev-режиме подгружает фикстуру динамическим `import()` внутри ветки
`if (import.meta.env.DEV)`. При сборке Vite подставляет `false`, ветка вырезается
как мёртвый код, и данные акций в бандл не попадают — проверяется так:

```bash
npm run build
grep -c "PROMOTIONS_DEV\|coralbonus.ru/promo" '@CMS/info-actions.html'   # → 0
```

Фикстуру нужно держать актуальной вручную — синхронно с тем, что отдаёт внешний скрипт.

> **Важно:** скрипт с данными должен быть подключён на странице **до** скрипта лендинга
> (обычный `<script>` в разметке или `defer` выше по документу). Если на момент
> монтирования глобала нет, акции не отрисуются, а в консоль уйдёт `console.warn`.

### Поля записи: обязательные и необязательные

Контракт описан интерфейсом `PromotionConfig` в `types/promotion.ts`, нормализация —
в `data/promoSchema.ts`.

**Обязательные:** `name` и `visual`. Без них карточку нечем нарисовать, поэтому запись
отбрасывается, а в интерфейсе появляется предупреждение с её номером.

**Все остальные поля необязательные, и мы их не подставляем.** Отсутствие поля — рабочий
сценарий, шаблон его обрабатывает:

| Нет поля | Что будет |
|---|---|
| `url` | вместо ссылки рисуется кнопка (для попапа) |
| `erid` | не рисуется плашка «Реклама» с тултипом |
| `promo_start` / `promo_end` | акция считается стартовавшей / бессрочной |
| `promo_end_text` | не рисуется строка со сроком |
| `filter` | акция видна только в табе «Все акции» |

Нормализация добавляет лишь производные поля, которых в конфиге нет: `id` (для `:key`),
`filtersArr` (разбор `filter`) и `isBonus`.

### Поле `entry_point` (аналитика кликов)

Отвечает за цель `entry-point` — клик по кнопке «Подробнее» до перехода по ссылке.
Три состояния, и они означают разное:

| Значение | Поведение |
|---|---|
| поля нет в объекте | клик намеренно не трекаем, директива не вешается — тишина |
| `entry_point: ""` | **ошибка контента**: клики теряются → предупреждение в интерфейсе |
| непустая строка | клик трекается с этим идентификатором |

Пустая строка почти всегда означает «поле добавили, но забыли заполнить», поэтому блок
показывает уведомление (antd Notification, стиль предупреждения) со списком таких акций:
`Проблемы в конфиге акций`. Нужно либо заполнить поле, либо убрать его из объекта —
тогда предупреждение исчезнет. Туда же попадают записи, отброшенные из-за отсутствия
обязательных полей.

Фолбэка на `name` намеренно нет: он маскировал бы недозаполненный конфиг и засорял
статистику непредсказуемыми значениями.

Уведомление видно в dev всегда, а на проде — только с флагом `?promo_debug=1`, чтобы можно
было проверить боевой конфиг, не показывая служебное сообщение пользователям.

> **Про импорты antd.** Подключаем только конкретные модули
> (`ant-design-vue/es/notification`), а не пакет целиком: динамический
> `import('ant-design-vue')` не тришейкается и утаскивает всю библиотеку — бандл
> распухает с 284 КБ до 1.5 МБ. Ленивая загрузка тут тоже не нужна: билдер инлайнит
> всё в один HTML, code splitting не работает, и чанк-обвязка лишь добавляет вес.
> Замеры по вариантам — в `ANALYSIS-2026.md`, пункт C26.

## Отличия от версии 2025

- Конфиг акций больше не лежит в бандле: на проде он приходит из внешнего скрипта
  сайта в `window._promotion_settings`, в dev — из локальной фикстуры (см. выше).
  Загрузка асинхронная, компонент показывает пустое состояние, если акций нет.
- Убрана зависимость от `usefuls.ts` (`hostReactAppReady`): монтирование выполняет
  builder, вызывая экспортируемую по умолчанию функцию блока.
- Удалены неиспользуемые пакеты `copy-to-clipboard` и `vue-clipboard`.
- Утилита `.no-scrollbar` перенесена из `Tabs.scss` в общие `_components.scss`.
- Аналитика: единый `config/brand.js` (бренд + счётчик + `reachGoal` с буфером),
  дедупликация показов по `id` акции, гарантия доставки цели перед переходом.
- Даты акций считаются по московскому времени независимо от часового пояса пользователя.
- Семантика и a11y: `<time datetime>`, корректная иерархия заголовков, табы на
  `<button role="tab">` с поддержкой клавиатуры.
